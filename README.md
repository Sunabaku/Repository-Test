## これが中見出し
埼玉湾ではムサシトミヨの養殖が盛んであり、ムサシトミヨの生産量は23年連続全国1位である。このことから埼玉県は4/700をムサシトミヨの日に指定し、イベントの開催や教育活動を行っている。
